# Raw data (never edit files here)

Download the monthly CSV from Public Health Scotland:
https://www.opendata.nhs.scot/dataset/monthly-accident-and-emergency-activity-and-waiting-times

Save it in this folder unchanged.

Notes from PHS:
- Monthly A&E activity and waiting-time data.
- Attendance category: New Planned, Unplanned, All (All = sum). Filter to one to avoid double counting.
- Use this monthly dataset when monitoring against the official 4-hour standard.
